How to use this planner
  1. Each day lists timed tasks with a link and a deliverable. Tick a task when its deliverable exists (not when you've merely read).
  2. Progress saves in this browser only. Saturday of Weeks 4, 8 and 13 is a buffer day: use it to catch up, not to add new work.
  3. Behind by more than 3 days? Drop the lightest task of each day for a week; never skip the project deliverables.
  4. End of each phase: do the self-assessment in the Rubric tab before moving on.
  5. Honest expectation: after 90 days you'll be interview-ready for entry-level GRC, not an expert.
